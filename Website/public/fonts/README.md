# PDF fonts

Noto Sans Regular and Bold, bundled under the SIL Open Font License in OFL.txt.
Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

These static TrueType fonts are loaded only when preparing a PDF. They are embedded in downloads to preserve accented names. Updating them requires checking the rendered export fixtures again.
